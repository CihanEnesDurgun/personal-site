## 🎯 Genel Bakış

Modern teknolojilerle geliştirilmiş, tam fonksiyonel kişisel web sitesi ve blog yönetim sistemi. Node.js backend API'si, güçlü admin paneli ve kullanıcı dostu arayüz ile profesyonel içerik yönetimi sunar.

Bu sürüm, sistemin ilk geliştirme aşamasını temsil eder ve temel özelliklerin tamamlandığı, ancak production ortamına henüz tam olarak deploy edilmediği bir versiyondur. Semantic Versioning standartlarına göre **v0.1.0**, aktif geliştirme aşamasında olan ve breaking changes içerebilecek bir sürümdür.

## 🛠️ Teknik Detaylar

### Frontend Teknolojileri
- **HTML5** - Semantic markup yapısı
- **CSS3** - Modern stiller, CSS variables, glassmorphism efektleri
- **JavaScript (ES6+)** - Modüler mimari, async/await, class-based yapı

- **cors** - Cross-Origin Resource Sharing yönetimi
- **express-rate-limit** - API rate limiting
- **node-cron** - Zamanlanmış görevler (session cleanup)

### Mimari Özellikler
- **RESTful API** - Standart HTTP metodları ve endpoint yapısı
- **Modüler JavaScript** - Her özellik ayrı modül (8 ana modül)
- **Server-side Session Management** - Otomatik cleanup ile oturum yönetimi

## 📦 Kurulum

### Gereksinimler
- Node.js v14.0.0 veya üzeri
- npm v6.0.0 veya üzeri

### Kurulum Adımları

```bash
# 1. Projeyi klonlayın
git clone <repository-url>
cd personal-site

# 2. Bağımlılıkları yükleyin
npm install

# 3. Environment dosyasını oluşturun
cp env.example .env
# .env dosyasını kendi ayarlarınıza göre düzenleyin

# 4. Backend server'ı başlatın
npm start

# Geliştirme modu için:
npm run dev
```

### Environment Değişkenleri

```env
# Güvenlik (Zorunlu)
JWT_SECRET=your-very-long-secret-key-minimum-32-characters
BCRYPT_SALT_ROUNDS=12

# Oturum Yönetimi (Opsiyonel)
SESSION_TIMEOUT=60
SESSION_IDLE_TIMEOUT=15
MAX_SESSIONS_PER_USER=3
SESSION_CLEANUP_INTERVAL=5

# Rate Limiting (Opsiyonel)
RATE_LIMIT_MAX=100

# CORS (Production için gerekli)
CORS_ORIGIN=https://yourdomain.com

# Varsayılan Admin Şifresi (Opsiyonel)
DEFAULT_ADMIN_PASSWORD=your-secure-password
```

## 🚀 Kullanım

### Admin Panel Erişimi
1. Tarayıcıda `/admin/login.html` adresine gidin
2. Kullanıcı bilgilerinizle giriş yapın
3. Dashboard'dan tüm özelliklere erişebilirsiniz

### Blog Yazısı Oluşturma
1. Admin panelinde "Blog Yönetimi" sekmesine geçin
2. "Yeni Blog Yazısı" butonuna tıklayın
3. Markdown editörde içeriğinizi oluşturun
4. Başlık, özet, etiketler ve kapak resmi ekleyin
5. "Kaydet" ile yazınızı yayınlayın

### Ana Sayfa Özelleştirme
1. Admin panelinde "Ana Sayfa Editör" sekmesine geçin
2. Avatar, isim, başlık ve bio bilgilerini düzenleyin
3. Sosyal medya linklerinizi ekleyin
4. Live preview ile değişiklikleri görün
5. "Kaydet" ile değişiklikleri uygulayın

### Tema Yönetimi
1. Admin panelinde "Tema Ayarları" sekmesine geçin
2. Renk paletini özelleştirin
3. Light/Dark tema ayarlarını yapın
4. Önizleme ile sonuçları görün
5. Değişiklikler tüm cihazlarda senkronize olur

## 🔧 API Endpoints

### Kimlik Doğrulama
- `POST /api/login` - Kullanıcı girişi
- `POST /api/logout` - Oturum kapatma
- `GET /api/session` - Oturum durumu
- `GET /api/sessions/stats` - Oturum istatistikleri

### Blog İşlemleri
- `GET /api/posts` - Tüm blog yazıları
- `GET /api/posts/:slug` - Tek blog yazısı
- `POST /api/posts` - Yeni blog yazısı oluştur
- `PUT /api/posts/:slug` - Blog yazısı güncelle
- `DELETE /api/posts/:slug` - Blog yazısı sil

### Tema Yönetimi
- `GET /api/theme` - Tema ayarlarını getir
- `PUT /api/theme` - Tema ayarlarını güncelle

### Dosya İşlemleri
- `POST /api/upload` - Resim yükle
- `POST /api/admin/set-icon` - Sistem ikonu ayarla
- `GET /api/gallery/:folder` - Galeri resimleri

### Ana Sayfa
- `GET /api/site` - Site bilgileri
- `PUT /api/site` - Site bilgilerini güncelle

### Hesap Yönetimi
- `PUT /api/user/username` - Kullanıcı adı değiştir
- `PUT /api/user/password` - Şifre değiştir

### Sistem
- `GET /api/stats` - Dashboard istatistikleri
- `GET /api/health` - Sistem sağlık kontrolü
