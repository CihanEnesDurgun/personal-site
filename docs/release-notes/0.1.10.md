# 📄 Versiyon Notları - v0.1.10

_Yayın Tarihi: Nisan 2026_

## 🌟 Genel Bakış

`v0.1.10` sürümü, admin panelinin dashboard ekranını kapsamlı bir şekilde yeniden tasarlayarak blog yazılarını ana siteyle uyumlu kart görünümüne kavuşturmuştur. Kart aksiyon butonları üç nokta dropdown menüsüyle sadeleştirilmiş, filtre seçenekleri genişletilmiş ve markdown editöründeki kritik bir görsel kaybı hatası giderilmiştir.

## ✨ Yeni Özellikler ve Geliştirmeler

### Admin Dashboard Kart Tasarımı
- **Tablo → Kart Grid Dönüşümü:** Blog yazıları listesi, `repeat(auto-fill, minmax(280px, 1fr))` grid yapısıyla kart görünümüne geçirildi.
- **Ana Site Uyumu:** Kart boyutları, thumbnail yüksekliği (`clamp(180px, 16vw, 220px)`), başlık fontu (`1.17rem, 700`), meta bilgileri ve excerpt stili ana sitedeki blog kartlarıyla eşleştirildi.
- **Kapak Fotoğrafı Entegrasyonu:** Her kart, ilgili yazının kapak fotoğrafını gradient overlay ile birlikte gösteriyor; durum bilgisi ve görüntülenme sayısı thumbnail üzerinde yer alıyor.
- **Öne Çıkan Rozeti:** Öne çıkan yazılar için kart üzerinde altın renkli rozet eklendi.

### Kart Aksiyon Butonları (Üç Nokta Menü)
- **Sadeleştirilmiş Buton Yapısı:** "Düzenle" ve "Yayınla" (taslaklar için) ana buton olarak korundu; diğer tüm aksiyonlar (Önizle, Zamanla, Öne Çıkar, Sil) üç nokta (⋯) dropdown menüsüne taşındı.
- **Dropdown Menü:** Animasyonlu açılış, tıklama-dışı-kapanma, tehlikeli aksiyonlar (Sil) için kırmızı vurgu ve ayırıcı çizgi içeren modern menü tasarımı.

### Filtre Seçenekleri Güncelleme
- **"Taslaklar" Filtresi:** Dropdown'a sadece taslak durumundaki yazıları listeleyen yeni filtre eklendi.
- **"Yayındakiler" Filtresi:** "Son Yazılar" seçeneği kaldırılarak yerine taslak olmayan tüm aktif yazıları listeleyen "Yayındakiler" filtresi eklendi.

## 🐛 Giderilen Hatalar

### Markdown Editörü Görsel Kaybı (Kritik)
- **Marked API Uyumsuzluğu:** `marked` kütüphanesinin yeni versiyonlarında `renderer.image()` fonksiyonu string yerine token object göndermekteydi. Eski kod bu object'i `[object Object]` olarak kaydediyordu. Renderer, hem eski `(href, title, text)` hem yeni `(token)` API'sini destekleyecek şekilde güncellendi.
- **Relative Path Düzeltmesi:** Markdown editörü `/markdown-editor/` dizininde çalışırken, görsellerin `images/...` şeklindeki path'leri yanlış çözümleniyordu. Kapak fotoğrafları, markdown görselleri ve raw HTML `<img>` etiketleri için `../` prefix sistemi eklendi.
- **`data-original-src` Koruması:** Görsellerin orijinal path'leri `data-original-src` attribute'unda saklanarak, kaydetme sırasında doğru markdown üretilmesi garanti altına alındı.

### CSS Specificity Düzeltmesi
- **Başlık Kalınlığı:** Global `.post-title { font-weight: 500 }` kuralının kart başlıklarını override etmesi, `.post-card-title .post-title { font-weight: 700 }` ile daha yüksek specificity tanımlanarak çözüldü.
