# 📄 Versiyon Notları - v0.2.0

_Yayın Tarihi: 17 Temmuz 2026_

## 🌟 Genel Bakış

`v0.2.0` sürümü, siteyi cPanel'e ilk kez yayınlamadan önce yapılan kapsamlı bir güvenlik
denetiminin ve deploy altyapısı kurulumunun sonucudur. İki kritik güvenlik açığı kapatıldı,
deploy tamamen yeniden tasarlandı (hosting SSH sağlamadığı ortaya çıktığında akış buna göre
uyarlandı) ve proje genelinde adlandırma/yapı tutarlılığı sağlandı.

## 🔒 Güvenlik

### Kritik — Sızmış JWT Secret
`.env` dosyasındaki gerçek `JWT_SECRET` değeri, dokümantasyonda "örnek" olarak yıllardır
public repo'da duruyordu. Bu anahtar admin oturum token'larını imzaladığı için, onu bilen
biri şifre bilmeden admin olabilirdi. Değer placeholder ile değiştirildi, gerçek anahtar
rotate edildi. Aynı sebeple `scripts/setup-users.js` içine gömülü admin şifresi de
kaldırıldı — artık yalnızca `.env`'deki `DEFAULT_ADMIN_PASSWORD`'dan okunuyor.

### Kritik — Taslak Yazı Sızıntısı
`content/posts.json` ve `content/posts/*.md` statik dosya sunumuyla herkese açıktı.
`blog.js`'teki durum filtresi yalnızca tarayıcıda çalışıyordu — güvenlik sınırı değildi.
Taslak önizlemesi de `?preview=true` URL parametresine dayanıyordu, kimlik doğrulaması
değildi. Artık bu rotalar sunucu tarafında filtreleniyor: yetkisiz istekte yayınlanmamış
kayıtlar listeden çıkarılıyor ve markdown dosyaları 404 dönüyor; admin token'ı ile önizleme
olduğu gibi çalışmaya devam ediyor.

### Kimliksiz Deploy Webhook'u
`/api/webhook/deploy`, `GITHUB_WEBHOOK_SECRET` tanımlı değilken imza doğrulamasını
tamamen atlıyordu — internetteki herhangi biri sahte bir istekle sunucuda `deploy.sh`
çalıştırabilirdi. Endpoint tamamen kaldırıldı; uygulamada artık shell komutu çalıştırma
yeteneği yok.

## 🚀 Deploy Altyapısı

Hosting firmasına (Veridyen) danışıldığında paylaşımlı pakette **SSH sağlanmadığı**,
yalnızca cPanel üzerinden erişilen bir Terminal olduğu netleşti. Bu yüzden ilk tasarlanan
"yerelden cPanel'e push" akışı, "sunucudan GitHub'dan pull" akışına çevrildi:

- **`.cpanel.yml`**: Repo'ya her pull sonrası otomatik çalışır — yalnızca kod dosyalarını
  kopyalar, bağımlılıkları kurar, Passenger'ı yeniden başlatır. `content/`, `images/`,
  `data/` bilerek kapsam dışı: admin paneli bunları çalışma anında yazıyor, deploy'a dahil
  edilirse panelden yayınlanan içerik her deploy'da eski sürümle ezilir.
- **`scripts/server-deploy.sh`**: cPanel Terminal'den çalıştırılır; `git pull` yapar ve
  `.cpanel.yml`'i tetikler.
- **`scripts/content-pull.js`**: Yerel bilgisayardan sunucudaki içeriği indirmek için
  SSH yerine sitenin kendi HTTP arayüzünü kullanır. Admin girişiyle taslaklar da iner;
  girişsiz kullanımda yereldeki taslaklar korunur (üzerine yazılmaz).

## 🎨 Diğer İyileştirmeler

- **SEO/Paylaşım:** Yazı ve proje sayfalarına sekme başlığı ve `og:`/`twitter:` meta
  etiketleri eklendi (`src/js/meta-tags.js`). Önceden tüm yazılar aynı statik "Yazı"
  başlığını paylaşıyordu.
- **Türkçe dosya adları:** Görsel yüklemede Türkçe karakterli adlar (`görsel.png`)
  mojibake yüzünden `ga-rsel` gibi okunamaz hale geliyordu; düzeltildi.
- **Adlandırma tutarlılığı:** `blogstyle.css` → `blog.css`, `projectstyle.css` →
  `projects.css`, `markdown-editor/script.js` → `editor.js` ve benzeri. `admin/js/`
  altında hiçbir sayfanın yüklemediği 7 ölü modül kaldırıldı.
- **Sürüm numaraları sadeleşti:** Araç ekleri (`-cla`, `.anti`, `.crs`) kaldırıldı, düz
  SemVer'e geçildi. Sürüm süreci `docs/guides/release-process.md`'de belgelendi.
- Proje klasörü üç kat iç içe geçmiş yoldan tek bir konuma taşındı.
