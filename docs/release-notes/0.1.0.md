# 📄 Versiyon Notları - v0.1.0

**Yayın Tarihi:** 19 Kasım 2025  
**Durum:** İlk Geliştirme (Initial Release)  
**Kod Adı:** *Genesis Core*

---

## 🚀 Genel Bakış
`v0.1.0` sürümü, projenin temel yapı taşlarının atıldığı, modüler mimarinin ve core API servislerinin kurulduğu başlangıç sürümüdür. Bu versiyon ile birlikte Vanilla JS ve Node.js tabanlı, dış bağımlılığı minimize edilmiş, taşınabilir bir blog ekosistemi inşa edilmiştir.

---

## 🏗️ Mimari Tasarım ve Core Altyapı
Sistemin iskeleti, ölçeklenebilir ve bağımsız bir yapı kurmak üzere şu bileşenlerle oluşturuldu:

- **Modüler JavaScript Mimarisi:** Admin paneli ve frontend, ES6 modülleriyle her özelliğin (Blog, Galeri, Tema vb.) izole edildiği bir yapıya kavuşturuldu.
- **No-SQL Veri Katmanı:** Taşınabilirliği (Portability) maksimize etmek için RDBMS yerine JSON tabanlı veritabanı ve Markdown dosya sistemi tercih edildi.
- **Hibrit Kimlik Doğrulama:** JWT (JSON Web Tokens) ile stateless erişim ve server-side session takibi ile güvenli bir yönetim katmanı oluşturuldu.
- **Merkezi Yazma Deneyimi:** Post sayfasıyla görsel uyumlu, kullanıcı dostu Markdown editörü ve içerik yönetim merkezi devreye alındı.

---

## ✨ Öne Çıkan Özellikler

### 🌐 Frontend (İstemci)
- **Fluid UI:** Modern responsive tasarım prensipleriyle mobil-öncelikli (mobile-first) arayüz.
- **Native Tema Motoru:** CSS Variables ve LocalStorage entegrasyonuyla server-side senkronize Dark/Light mode.
- **İçerik Optimizasyonu:** Otomatik okuma süresi hesaplama, SEO meta etiketleri ve temel RSS desteği.

### 🔐 Admin Control Center
- **Gelişmiş Galeri Yönetimi:** Klasör tabanlı organizasyon, sürükle-bırak yükleme ve metadata düzenleme özellikleri.
- **Dinamik Dashboard:** Blog istatistikleri, sistem durumu ve aktif oturum izleme paneli.
- **Canlı Önizleme (Live Preview):** Ana sayfa ve blog içerikleri için anlık görsel geri bildirim sistemi.

---

## 🛡️ Güvenlik ve Dayanıklılık
Sistem, MVP aşamasında dahi temel güvenlik standartlarını karşılayacak şekilde sıkılaştırıldı:

- **Bcrypt Password Storage:** Şifreler 12 salt round ile geri döndürülemez şekilde hashlenerek saklandı.
- **Rate-Limiting & CORS:** API endpointleri brute-force saldırılarına karşı sınırlandırıldı ve üretim ortamı için CORS politikaları uygulandı.
- **Session Hijacking Koruması:** IP ve User-Agent doğrulamasıyla oturum güvenliği artırıldı.

---

## 🛠️ Teknik Yığın (Stack)
- **Runtime:** Node.js (v14+)
- **Backend:** Express.js, JWT, Bcrypt, Multer
- **Frontend:** HTML5, CSS3 (Variables, Glassmorphism), Vanilla JavaScript
- **Utilities:** fs-extra, node-cron, body-parser
