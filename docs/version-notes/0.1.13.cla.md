# 📄 Versiyon Notları - v0.1.13.cla

_Yayın Tarihi: Temmuz 2026_

## 🌟 Genel Bakış

`v0.1.13.cla` sürümü, siteye tamamen yeni bir **"Projeler"** bölümü kazandırıyor. Blog altyapısının projelere özel bir paraleli kurularak; kendi liste sayfası, kendi detay sayfası, kendi yönetim arayüzü ve kendi editör modu oluşturuldu. Proje kartları, GitHub'ın linguist çubuğuna benzer şekilde kullanılan **dil/teknoloji yüzdelerini** renkli bir çubukla gösteriyor. Proje detay sayfası ise otomatik kayan **fotoğraf galerisi**, **kod örneği modalı** ve canlı GitHub API verisiyle beslenen **repo önizleme kartı** içeriyor.

## ✨ Yeni Özellikler

### Projeler Bölümü (Public)
- **Yeni Navigasyon:** Üst bar `Ana Sayfa · Blogum · Projelerim · İletişim` olarak güncellendi; tüm sayfalarda (ana sayfa, blog, yazı, projeler, proje) tutarlı hale getirildi.
- **Ana Sayfa Önizlemesi:** Blog önizlemesinin altına, iletişim bölümünün üstüne projeler önizleme bölümü ve "Daha Fazla Proje" butonu eklendi. En fazla 6 proje gösteriliyor (öne çıkanlar üstte).
- **Projeler Sayfası (`projects.html`):** Blog listesiyle birebir aynı tasarım dili ve responsive davranış; arama, etiket çipleri ile filtreleme. Arama; başlık, özet, etiket, teknoloji adı ve içerik üzerinde çalışıyor.
- **Dil/Teknoloji Çubuğu:** Proje kartlarında, blog kartından tek farkı oluşturan renkli yüzde çubuğu ve altında dil listesi (GitHub linguist tarzı). Mobil kompakt kartlarda çubuk korunup açıklama listesi gizleniyor.

### Proje Detay Sayfası (`project.html`)
- **Kayar Galeri:** Ana görselin hemen altında otomatik kayan (3.5 sn) fotoğraf galerisi; üzerine gelince duruyor, ok butonları ve nokta göstergeleriyle manuel gezinme mümkün. Tek görselde kontroller otomatik gizleniyor.
- **Metin Bölümü:** Blog yazı sayfasıyla aynı markdown render'ı ve stilleri (`post.css` yeniden kullanıldı); görseller otomatik `<figure>` + açıklama ile sarmalanıyor.
- **Kod Örneği Modalı:** Projeye özel kod bloğu, koyu temalı bir kutuda gösteriliyor; "Büyüt" ile tam ekran modalda açılıyor (ESC / arka plan tıklaması ile kapanıyor).
- **GitHub Repo Önizleme Kartı:** Tarayıcı çerçevesi görünümünde; repo adı, açıklama, yıldız/fork/açık konu/lisans, GitHub API'den gelen gerçek dil dağılımı ve render edilmiş README. Hata/limit durumunda zarif bir "GitHub'da Aç" fallback kartına düşüyor.
- **Güvenlik:** Taslak/zamanlanmış projeler herkese açık görüntülenemiyor; yalnızca admin önizleme linkiyle (`?preview=true`) açılabiliyor (blog tarafındaki v0.1.12 düzeltmesiyle aynı mantık).

### Admin Paneli
- **Yeni Proje Yazısı Butonu:** Dashboard'da "Yeni Blog Yazısı" butonunun yanına eklendi; editörü proje modunda açıyor.
- **Blog/Proje Ayrımı:** Dashboard'da bloglardan bağımsız bir "Projeler" yönetim bölümü; kendi arama kutusu ve durum filtresiyle (Tümü / Taslaklar / Yayındakiler / Öne Çıkan).
- **Proje Kartları:** Kapak görseli, durum rozeti, görüntülenme sayısı, dil çubuğu ve aksiyonlar — Düzenle, Yayınla, Önizle, Öne Çıkar, Taslağa Çek, Sil.
- **İstatistik Ayrımı:** İstatistikler sekmesine "Proje İstatistikleri" (toplam proje görüntüleme, toplam proje, yayında/taslak) ve "Popüler Projeler" kartları eklendi; blog istatistiklerinden ayrı hesaplanıyor.

### Markdown Editörü — Proje Modu
- **`?type=project` Modu:** Editör, blog akışının tamamını (markdown araç çubuğu, kapak fotoğrafı, canlı önizleme, MD önizleme) koruyarak proje modunda açılıyor; başlık ve kaydet butonu proje diline uyarlanıyor.
- **Projeye Özel Alanlar:** Kaydet formuna eklenen alanlar — GitHub repo linki, dinamik dil satırları (ad + yüzde + renk seçici), kod örneği (dil + kod) ve kayar galeri için çoklu fotoğraf yükleme (küçük görsel önizlemeleri ve kaldırma butonuyla).
- **Düzenleme Desteği:** Mevcut bir proje düzenlenirken tüm proje alanları otomatik dolduruluyor.

## 🔧 Teknik Detaylar

### Veri Modeli
- **Yeni Dosyalar:** `content/projects.json` (metadata) ve `content/projects/*.md` (içerik) — blog'un `posts.json` + `content/posts/` yapısının paraleli.
- **Proje Şeması:** Blog alanlarına ek olarak `languages[{name, percent, color}]`, `gallery[]`, `githubUrl`, `codeSample{language, code}`.
- **Yeni Görsel Klasörleri:** `images/project-covers`, `images/project-gallery`, `images/project-content` (upload allowlist'ine eklendi).

### Sunucu (server.js)
- **Yeni API'ler:** `GET/POST /api/projects`, `GET/PUT /api/projects/:slug`, `PATCH /api/projects/:slug/featured`, `POST /api/projects/:slug/publish`, `DELETE /api/projects/:slug`, `POST /api/projects/:slug/restore`, `DELETE /api/projects/:slug/permanent`, `POST /api/analytics/track-project`.
- **GitHub Proxy (`GET /api/github/repo-preview`):** CSP `connect-src 'self'` olduğu için istemci doğrudan `api.github.com`'a erişemez. Sunucu proxy'si repo meta + diller + README'yi çekiyor, 10 dakika önbellekliyor ve `GITHUB_TOKEN` ortam değişkeni varsa kimlikli istek atıyor (rate limit yönetimi).
- **Girdi Doğrulama:** `buildProjectFields()` ile dil yüzdeleri 0-100 aralığına, renkler hex formatına, GitHub linki `github.com` alan adına kısıtlanıyor (XSS/enjeksiyon koruması).
- **SEO:** Sitemap'e `projects.html` ve halka açık proje sayfaları eklendi; taslak/zamanlanmış projeler dahil edilmiyor.
- **İstatistik:** `stats.projectViews` ve günlük proje görüntüleme takibi; `/api/stats` ve `/api/stats/analytics` proje sayaçlarıyla genişletildi.

### Güvenlik Notları
- Dil çubuğu segmentleri, DOMPurify'ın stil temizliğini aşmak için `data-*` özniteliği + JS ile uygulanıyor (inline stil enjeksiyonu yerine XSS-güvenli yöntem).
- GitHub README içeriği DOMPurify ile sanitize edilerek render ediliyor.
- Yeni public sayfalar (`projects.html`, `project.html`) statik dosya allowlist'ine eklendi.
